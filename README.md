# -tude_des_cotations_de_mati-res_premi-res
📊 Analyse de séries temporelles de cotations de matières premières (café, cacao, jus d'orange, sucre, pétrole Brent) depuis 2010. Modélisation par régression linéaire par morceaux avec R (tidyverse, ggplot2). Projet BUT Science des Données - IUT Lisieux 2024-2025.
